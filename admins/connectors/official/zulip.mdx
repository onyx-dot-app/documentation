## How it works

The Zulip connector indexes messages from every stream the bot user can read.
Onyx groups the messages of a topic into one document per week and links each document back to the topic in Zulip.

Permission sync is not available. **Document Access** can be **Everyone in Your Organization** or **Specific Groups**.
**Specific Groups** is a paid feature: the Business and Enterprise tiers on Onyx Cloud,
and the Enterprise Edition when self-hosted.

The connector is available in all editions.

<Note>
  Onyx indexes only the streams the bot is subscribed to or can read.
  Subscribe the bot to each stream you want to index.
</Note>

## Setting up

### Authorization

<Steps>
  <Step title="Understand Zulip bot auth">
    Onyx connects to Zulip as a Zulip bot. The bot authenticates with the `zuliprc` config format.
    For more context directly from Zulip, refer to the following docs:
    - https://zulip.com/api/running-bots
    - https://zulip.com/api/configuring-python-bindings
  </Step>

  <Step title="Create a Zulip bot">
    In Zulip, open **Personal settings** → **Bots** and add a new bot.

    <img className="rounded-image" src="/assets/admins/connectors/zulip/ZulipBot.png" alt="Creating a bot user in Zulip settings"/>
  </Step>

  <Step title="Copy zuliprc contents">
    Download or copy the bot's `zuliprc` file, see the red arrow below:

    <img className="rounded-image" src="/assets/admins/connectors/zulip/ZulipRC.png" alt="Zulip bot page highlighting the zuliprc configuration download"/>

    Keep the text of this file for the next step.
  </Step>
</Steps>

### Indexing

<Steps>
  <Step title="Open the Zulip connector">
    In the Admin Panel, go to **Connectors** and select **Zulip**.
  </Step>

  <Step title="Add the credential">
    Under **Authentication Account**,
    select **New Zulip Account** and paste the `zuliprc` text into **Zuliprc Content**.
  </Step>

  <Step title="Get the realm name and URL">
    Find your Zulip realm name and URL, see below:

    <img className="rounded-image" src="/assets/admins/connectors/zulip/ZulipRealmURL.png" alt="Zulip UI showing Realm and URL details"/>
  </Step>

  <Step title="Enter the realm name and URL">
    Enter the **Realm Name** and the **Realm URL**, for example `https://example.zulipchat.com`.

    <img className="rounded-image" src="/assets/admins/connectors/zulip/OnyxZulipConfig.png" alt="Onyx Zulip connector configuration with realm name and realm URL"/>
  </Step>

  <Step title="Set access and create">
    Under **Connector Settings**, choose **Document Access** and click **Create Connector**.
  </Step>
</Steps>

Watch the first index attempt on the **Indexing Status** page. Later runs index new messages only.

---
title: "S3 Assume Role"
description: "This method automatically uses the IAM role attached to your EC2 instance to access S3 buckets. No manual credential entry is required."
---

### Prerequisites

This method works only for a self-hosted Onyx that runs on an Amazon EC2 instance. It is not available on Onyx Cloud.

- Ensure your EC2 instance has an IAM role attached.
- Verify the instance profile is properly configured via AWS Console under **EC2 › Instance Settings
  › Attach/Replace IAM role**.

### Updating the Existing IAM Role

Your EC2 instance already has an IAM role attached. Add the S3 permissions to it:

<Steps>
  <Step title="Open role in IAM">
    In AWS Console, go to **IAM › Roles** and find your EC2 instance's existing role.
  </Step>

  <Step title="Attach S3 policy">
    Click on the role and go to the **Permissions** tab. Click **Add permissions › Attach policies**.
    Search for and select **AmazonS3ReadOnlyAccess** policy. Click **Attach policies**.
  </Step>
</Steps>

For finer control, create a custom inline policy instead:

<Steps>
  <Step title="Create inline policy">
    In the same role's **Permissions** tab, click **Add permissions › Create inline policy**.
    Switch to JSON and add this policy (replace `your-source-bucket-name`):

   ```json
   {
     "Version": "2012-10-17",
     "Statement": [
       {
         "Effect": "Allow",
         "Action": [
           "s3:GetObject",
           "s3:ListBucket"
         ],
         "Resource": [
           "arn:aws:s3:::your-source-bucket-name",
           "arn:aws:s3:::your-source-bucket-name/*"
         ]
       }
     ]
   }
   ```

    Name the policy (e.g., `OnyxS3Access`) and click **Create policy**.
  </Step>
</Steps>

The connector detects and uses the EC2 instance's IAM role to access your S3 buckets.

### Credential Entry in Onyx

When you create the authentication account for the S3 connector in Onyx:

<Steps>
  <Step title="Open the Assume Role tab">
    Select the **Assume Role** tab.
  </Step>

  <Step title="No credentials required">
    Enter a **Display Name** and select **Create**. The connector uses the role attached to your EC2 instance.
  </Step>
</Steps>

After you update your EC2 instance's role with S3 permissions,
follow the [indexing steps in the overview](./overview#indexing) to configure your S3 connector.

## How it works

The Highspot connector indexes the content items in your Highspot instance.
It indexes either the Spots you name or every Spot the API user can view and download from.
Each content item becomes one document.

Onyx checks Highspot for new and changed items on the connector's refresh schedule. The default is every **30** minutes.
The Highspot connector does not support **Sync with Highspot** (permission sync).

## Setting up

### Authorization

> **IMPORTANT:** Highspot Platform Plus is an add-on feature that provides access to the API. Without Platform Plus, users cannot access the API features required for this connector. Please ensure your organization has purchased the Platform Plus add-on before proceeding.

#### Enabling Developer Options

<Steps>
  <Step title="Open company settings">
    Log into your Highspot account as an administrator.
    Click on your profile icon in the top right corner and select "Settings".
    Select "your company" under company settings.
  </Step>

  <Step title="Enable API access">
    Navigate to "Access and Privacy" and click on "API Access". Add the user(s)
    who will need to generate API keys and secrets. Confirm "API Access for Users" is enabled.
  </Step>
</Steps>

<img className="rounded-image" src="/assets/admins/connectors/highspot/highspot_enable_developer.png" alt="Highspot company settings showing Access and Privacy with API access"/>

#### Generating API Credentials

<Steps>
  <Step title="Open Developer settings">
    Log in as the user who has been granted API access.
    Click on the profile icon in the top right corner and select "Settings".
    Look for the "Developer" tab under user settings.
  </Step>

  <Step title="Generate API key">
    Navigate to the developer section and generate a new API key. After generation, you'll receive a key and secret.

    <img className="rounded-image" src="/assets/admins/connectors/highspot/highspot_generate_api.png" alt="Highspot user Developer settings generating an API key and secret"/>
  </Step>

  <Step title="Record credentials">
    Note the API key, the secret and the API base URL of your Highspot region,
    for example `https://api-su2.highspot.com/v1.0/`. You need them to create the credential in Onyx.
  </Step>
</Steps>

### Indexing

<Steps>
  <Step title="Open the Highspot connector">
    Go to **Admin Panel → Connectors** and select **Highspot**.
  </Step>

  <Step title="Create a credential">
    Select **New Highspot Account**. Enter the API base URL in **Highspot URL**,
    the API key in **Highspot Key** and the secret in **Highspot Secret**, then select **Create**.
  </Step>

  <Step title="Choose what to index">
    Under **Highspot Content to Index**, select one option:
    - **Specific Spots**: enter the names of the Spots to index in **Spot Name(s)**. Names are not case-sensitive.
    - **Everything**: index every Spot the API user can view and download from.
  </Step>

  <Step title="Choose document access">
    Under **Document Access**, select **Everyone in Your Organization** or **Specific Groups**.
    **Specific Groups** needs the Business or Enterprise tier on Onyx Cloud, or the Enterprise Edition when self-hosted.
  </Step>

  <Step title="Start indexing">
    Give the connector a name and select **Create Connector** to start indexing.
  </Step>
</Steps>

The Image Generation action lets your Agents create images from text prompts.
The model can also edit an image the user attached, or one it generated earlier in the conversation,
instead of generating a new one from scratch. Once an admin connects an image model and sets it as the default,
any chat model in Onyx can invoke the action.

## Supported Models

| Model | Provider |
| ----- | -------- |
| GPT Image 2.5 Flare | OpenAI / Azure OpenAI |
| GPT Image 2.5 Sunburst | OpenAI / Azure OpenAI |
| GPT Image 2 | OpenAI / Azure OpenAI |
| GPT Image 1.5 | OpenAI / Azure OpenAI |
| GPT Image 1 | Azure OpenAI |
| Gemini 2.5 Flash Image (Nano Banana) | Google Cloud Vertex AI |
| Gemini 3 Pro Image (Nano Banana Pro) | Google Cloud Vertex AI |

<Note>
  OpenAI retired GPT Image 1 and Google retired Gemini 3 Pro Image Preview.
  Onyx hides these models unless they are already connected. If one of them is still connected,
  the page shows a warning. Connect another model, set it as the default, then disconnect the retired model.
</Note>

## Configuration

<Steps>
  <Step title="Open Image Generation">
    Open the **Admin Panel** and select **Image Generation** in the sidebar.

    <img className="rounded-image" src="/assets/admins/actions/image_generation_overview.png" alt="Image Generation page in the Onyx Admin Panel"/>
  </Step>

  <Step title="Connect a Model">
    The page lists the available models grouped by provider: **OpenAI**, **Azure OpenAI**,
    and **Google Cloud Vertex AI**.

    Click **Connect** on a model. A dialog opens where you enter the provider credentials:

    <Tabs>
      <Tab title="OpenAI">
        - **API Key**: Your OpenAI API key.
      </Tab>

      <Tab title="Azure OpenAI">
        - **API Key**: Your Azure OpenAI API key.
        - **Target URI**: The endpoint target URI from Azure OpenAI. It must include the endpoint base, the
        deployment name, and the `api-version` query parameter.
      </Tab>

      <Tab title="Google Cloud Vertex AI">
        - **Authentication Method**: Choose **Service Account JSON** or **Workload Identity (GKE)**.
        - **Credentials File** (Service Account JSON): Upload or paste the service account key JSON file.
        - **GCP Project ID** (Workload Identity): The project where Vertex AI is enabled. Onyx authenticates with the
        service account bound to its pod.
        - **Location**: The Google Cloud region for your Vertex AI models.
      </Tab>
    </Tabs>

    Onyx tests the credentials before it saves them. If the test fails, the dialog shows the error and nothing is saved.
  </Step>

  <Step title="Set the Default Model">
    Click **Set as Default** on the model you want to use.
    The model marked **Current Default** generates images when users ask for them in chat.
    Only one model can be the default.

    - To **change the default**: Click **Set as Default** on another connected model.
    - To **clear the default**: Click the **Current Default** badge. Image generation is turned off until you set
    another default.
    - To **edit credentials**: Click the **Edit** (gear) icon on the model.
    - To **disconnect a model**: Click the **Disconnect** icon. If the model is the current default, the dialog asks
    you to choose a replacement default or **No Default**, which turns image generation off.
  </Step>
</Steps>

## Enable Image Generation for Agents

Image generation does not appear in chat until a default model is set, even if an Agent has the action turned on.

- **Default Chat**: Go to **Admin Panel > Chat Preferences > Actions & Tools** and turn on **Image Generation**.
- **Custom Agents**: In the [Agent editor](/admins/agents/overview), open **Actions** and turn on
  **Image Generation**. The toggle stays disabled until an admin connects a model.

## Using Image Generation

When a user asks for an image, the Agent calls the default image model with a prompt it writes from the request.
The user sees a generating indicator, then the image inline in the response.
Generated images belong to the chat session that created them.

To edit an image, the user attaches it to the message (or refers to an image generated earlier in the chat)
and describes the change. The OpenAI and Azure OpenAI models accept up to 16 reference images;
the Vertex AI models accept up to 14.

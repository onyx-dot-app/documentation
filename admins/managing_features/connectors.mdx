Connectors bring documents from your tools into Onyx. Onyx indexes them so that chat, Search Mode,
and Agents can search them with each user's permissions applied.

## Where to manage connectors

| Page | Path | Use it to |
| --- | --- | --- |
| **Connectors** | `/admin/connectors` | Add a new connector. Pick a source, authenticate, and choose what to index. |
| **Indexing Status** | `/admin/indexing-status` | See every connector, its document count, last successful index, and errors. Pause, re-index, or delete a connector. |
| **Document Sets** | `/admin/documents/sets` | Group connectors into named sets for filtering and Agents. |
| **Index Settings** | `/admin/index-settings` | Change the embedding model and indexing options. Not shown on Onyx Cloud. |

Connectors are available in all editions. Permission-sync connectors, which mirror source permissions into Onyx,
need an Enterprise plan or Onyx Cloud.

## What admins can do

- **Add a connector**: Open **Connectors**, select a source, and authenticate with an API token, OAuth,
  or a service account. Scope what to pull, for example a Confluence space, Slack channels, or a shared drive.
  Saving starts the first index run.
- **Schedule refreshes**: Onyx polls each source on the schedule you set and removes documents deleted at the source.
- **Watch status**: **Indexing Status** shows indexing progress and errors.
  Onyx also raises a notification in the sidebar bell when a connector fails.
- **Control access**: Make a connector public or assign it to User Groups.
  Group assignment needs a Business or Enterprise plan.

See the [Connectors overview](/admins/connectors/overview) for setup guides for each source.

# Onyx Docs (moved)

The Onyx docs now live in the main repo: [`onyx-dot-app/onyx/documentation`](https://github.com/onyx-dot-app/onyx/tree/main/documentation).
Open docs pull requests there, in the same PR as the change they describe.

docs.onyx.app is published from the `docs/live` branch of `onyx` when a release becomes the latest stable version.

This repository is archived and read-only. Its history stays here. Onyx versions older than v5.0.2 still read
`changelog.mdx` from this repository for in-app release notes.

---
title: "Set User Role"
openapi: "PATCH /manage/set-user-role"
---

<Info>
  This endpoint applies only to Onyx versions before **v4.7**. For Onyx v4.7 and later,
  use [Set User Admin Access](/developers/api_reference/user_management/set_user_admin_access)
  to toggle Admin group membership. To grant other permissions, add the user to a group that grants them.
</Info>

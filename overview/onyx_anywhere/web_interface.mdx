The web app is the default way to use Onyx. It gives you the most complete experience.

The admin panel is also a web-app exclusive feature.
It is the easiest way to manage [Agents](/overview/core_features/agents), [Plugins](/overview/core_features/plugins),
[Connectors](/overview/core_features/connectors), users, settings and more.

<Tip>
  A great place to get familiar with the experience is the [Chat](/overview/core_features/chat) overview.
  See the [Admin](/admins/overview) section for managing the deployment.
</Tip>

If you deploy Onyx locally (guide [here](/deployment/getting_started/quickstart)),
open the web app at http://localhost:3000/.

The web app is also responsive, so you can use it from a mobile browser.

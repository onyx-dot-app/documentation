Onyx does not have a separate Workflows product. Use these features to automate work:

<CardGroup cols={2}>
  <Card title="Scheduled Tasks" icon="calendar-clock" href="/overview/core_features/craft_scheduled_tasks">
    Run a Craft prompt on a recurring schedule. Each run starts a fresh Craft session,
    can read and act in your connected Apps, and records its result in run history.
  </Card>

  <Card title="Craft Apps" icon="plug" href="/overview/core_features/craft_apps">
    Let Craft read live data and take approved actions in Slack, Gmail, Linear, GitHub, and other tools.
    Set each action to auto-approve, ask for approval, or disabled.
  </Card>

  <Card title="Agents" icon="robot" href="/overview/core_features/agents">
    Package instructions, knowledge, and actions into a reusable Agent for a repeat task, then share it with your team.
  </Card>

  <Card title="Plugins" icon="puzzle-piece" href="/overview/core_features/plugins">
    Connect MCP servers and OpenAPI plugins so agents can read from and write to external systems.
  </Card>
</CardGroup>

<Note>
  A Scheduled Task does not send you its result by default. Tell the prompt where to deliver the output,
  such as a Slack channel or an email, or review the result in the task's run history.
</Note>

## Overview

<img className="rounded-image" src="/assets/overview/core_features/voice_onyx_listening.png" alt="Voice Mode listening"/>

Voice Mode lets you talk to Onyx instead of typing. Speak your question and hear the answer read back.
Use it for hands-free work, brainstorming, or quick answers while you multitask.

## Requirements

Voice Mode is available in all editions, but an admin must set it up first.
An admin connects a speech-to-text and a text-to-speech provider at **Admin Panel → Voice**. Onyx supports OpenAI,
ElevenLabs, and Azure as voice providers.

Until an admin finishes setup, the microphone button in the input bar shows **Voice not configured**.

## Speech-to-Text

To talk to Onyx, click the **microphone** button in the input bar.
Onyx listens and transcribes your speech in real time.

- **Speak naturally**: Onyx transcribes your speech as you talk.
- **Stop recording**: Click the microphone button again to stop. Depending on your settings,
  Onyx sends the message or leaves it in the input bar for you to edit.

<Note>
  Voice Mode needs microphone access in your browser. Your browser asks for permission on first use.
</Note>

## Text-to-Speech

<img className="rounded-image" src="/assets/overview/core_features/voice_onyx_speaking.png" alt="Voice Mode speaking"/>

After you send a message, Onyx writes the answer and can read it back as audio.
The full text stays visible during playback.

<img className="rounded-image" src="/assets/overview/core_features/voice_read_aloud.png" alt="Read Aloud button"/>

If **Auto-Playback** is off, click **Read aloud** under a response to hear it.

## User Settings

Set your voice preferences under **Settings → Voice**:

<img className="rounded-image" src="/assets/overview/core_features/voice_user_settings.png" alt="Voice Mode Settings"/>

- **Auto-Send on Pause**: When on, Onyx sends your message when you pause speaking.
  When off, Onyx keeps listening until you click the microphone button to stop.
- **Auto-Playback**: When on, Onyx reads each response aloud as soon as it finishes,
  then starts listening again for a hands-free conversation. When off,
  Onyx shows the response as text and you play it manually.
- **Playback Speed**: Make spoken responses slower or faster.

For setup details, see the [admin configuration guide](/admins/actions/voice_mode).

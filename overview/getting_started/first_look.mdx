The Chat interface is a conversation with your AI Agents. You see it when you open Onyx and send a message.

<Tip>
  Use the **Chat / Search** toggle at the top of the page to switch between a conversation and a quick document search.
  The toggle appears when your admin has connected at least one source.
</Tip>

## How to use the Chat Interface

<Steps>
  <Step title="Type your message in the input bar" icon="pen-to-square">
    Try asking Onyx "What data do you have access to?"

    The input bar gives you control over how Onyx responds.
    We cover these options in more detail [below](#configure-your-chat-session).

    <img className="rounded-image" src="/assets/overview/core_features/start_chat.png" alt="Onyx Chat Interface"/>
  </Step>

  <Step title="Onyx processes your request" icon="gears">
    Onyx shows its reasoning and each Action it runs, such as Internal Search, Web Search, or Code Interpreter.
    For a simple question, Onyx answers immediately.

    <img className="rounded-image" src="/assets/overview/core_features/chat_first_message.png" alt="Onyx Chat Interface"/>
  </Step>

  <Step title="The AI responds conversationally" icon="pen-to-square">
    The default Onyx Agent can search your organization's connected sources.

    When Onyx runs Internal Search, it shows the documents it found and cites the sources in its answer.
    Click a citation to open the source document.

    <img className="rounded-image" src="/assets/overview/core_features/chat_response.png" alt="Onyx Chat Interface"/>
  </Step>

  <Step title="Continue your conversation or ask something new" icon="pen-to-square">
    Send a follow-up question, ask the Agent to do something with your documents, or start a new topic.

    You can also edit a message you sent, regenerate a response, switch between alternative responses, copy a response,
    and give a thumbs up or thumbs down. Click **Stop** at any time to stop generation.

    <img className="rounded-image" src="/assets/overview/core_features/follow_up.png" alt="Onyx Chat Interface"/>
  </Step>

  <Step title="After sending your message" icon="pen-to-square">
    Onyx saves your conversation in the **Recents** list of the Side Panel.

    <Info>
      Your admin can set a retention period that deletes old conversations automatically.
    </Info>

    <img className="rounded-image" src="/assets/overview/core_features/side_panel_rectangle.png" alt="Onyx Unified Interface Side Panel"/>
  </Step>
</Steps>

## Configure your Chat Session

<img className="rounded-image" src="/assets/overview/core_features/chat_options.png" alt="Onyx Chat Input Bar"/>

### Selecting an Agent

Onyx comes with one default Agent. It can use the Actions your admin has enabled, such as Internal Search, Web Search,
Image Generation, and Code Interpreter. Admins configure the default Agent in the Admin Panel.

The **Agents** section of the Side Panel lists the Agents you use most.
Click **More Agents** or **Explore Agents** to open the Agents page.
It shows every Agent that is published to you or shared with you. Click an Agent to start a new chat with it.

<Note>
  Older versions of Onyx called Agents "Assistants" or "Personas". They are the same thing.
</Note>

<img className="rounded-image" src="/assets/overview/GENERIC_PLACEHOLDER.png" alt="Onyx Agents page"/>

### Choose your Model

Each Agent has a default language model. To change the model for your session, click the model button in the input bar.

- **Auto** lets Onyx pick the best model for each message.
- **Reasoning Level** sets how much the model thinks before it answers, from Off to XHigh, on models that support it.
- **Temperature** sets how creative the model is: Deterministic, Balanced, or Creative.
- **Add Model** sends your message to two or three models at once so you can compare the answers.
  Your admin can turn Multi-Model Generation off.

<Tip>
  Can't find the model you want? Ask your admin to add it to your Onyx deployment.
</Tip>

<img className="rounded-image" src="/assets/overview/GENERIC_PLACEHOLDER.png" alt="Onyx Model Dropdown"/>

### Deep Research

Click the hourglass icon in the input bar to turn on **Deep Research**.

In Deep Research mode, Onyx plans the work, runs many searches and Actions,
and reflects on the results before it writes a detailed report. It takes longer than a normal response.

<Note>
  Your admin can turn Deep Research off for your deployment.
  Deep Research is not available when you send a message to more than one model.
</Note>

<img className="rounded-image" src="/assets/overview/GENERIC_PLACEHOLDER.png" alt="Onyx Deep Research toggle"/>

### Actions and Search Sources

Click the **Actions** button in the input bar to see the Actions available to your Agent.
You can turn each Action on or off for the current session, and you can force an Action for your next message.

Under **Internal Search**, click **Select Search Sources** to limit a search to specific connected sources.

The Actions menu also lists your **Plugins**. Plugins connect Onyx to your team's applications through MCP servers,
OpenAPI plugins, and Craft Apps. See [Plugins](/overview/core_features/plugins).

<img className="rounded-image" src="/assets/overview/GENERIC_PLACEHOLDER.png" alt="Onyx Actions menu"/>

### Attach Files

Click the plus icon in the input bar, then **Upload Files**, to add files to your chat session.
You can also drag a file onto the page or paste an image. Click **Recent Files** to reuse a file you uploaded before.

Uploaded files are private to you. To keep files and instructions together for repeated work,
create a [Project](#side-panel).

<img className="rounded-image" src="/assets/overview/GENERIC_PLACEHOLDER.png" alt="Onyx Attach Files"/>

### Voice

Click the microphone icon to dictate your message. Your admin must configure a voice provider first.
In your user **Settings**, under **Chat Preferences > Voice**, you can turn on auto-playback of responses,
auto-send when you pause, and set the playback speed. See [Voice Mode](/overview/core_features/voice_mode).

### Incognito Chat

Click **Incognito Chat** at the top of a new chat to start a private session.
An incognito chat does not appear in your Recents and Onyx does not use it to update your memories.
You cannot change this setting after you send the first message.

### Share and Export

From the chat menu at the top of the page you can:

- **Share** the chat as a read-only link.
- **Move to Project** to keep the chat with related files.
- **Export As** Markdown or plain text.
- **Delete** the chat.

## Code Execution

Code Interpreter lets Onyx run Python code in a secure sandbox directly from your chat. Use it to analyze data,
create charts, and process files.

### Features

- **Code Execution**: Run Python code snippets in a secure environment
- **Data Analysis**: Perform statistical analysis and data visualization
- **File Processing**: Read, write, and transform uploaded files
- **Interactive Development**: Iterate on code with immediate feedback

### Use Cases

- Data analysis and visualization
- File processing and transformation
- Statistical calculations

### Supported Languages

- Python

<Tip>
  Code Interpreter is available in all editions. Your admin turns it on in the Admin Panel.
  See [Code Interpreter](/overview/core_features/code_interpreter).
</Tip>

## Overview

Your experience with Onyx starts on the main page. From here, you can search your documents, generate code,
ask your Agents to do work, and more.

You can talk to Onyx like you talk to a colleague. Or you can search like you search the web.

<img className="rounded-image" src="/assets/overview/core_features/start_chat.png" alt="Onyx Unified Interface Chat"/>

## Chat vs. Search

Sometimes you want to talk with an AI Agent to get a summary, revise your writing, or get help with a task. Other times,
you only want to find a document you know is in the system.

Use the **Chat / Search** toggle at the top of the page:

- **Chat**: Conversation and research. Onyx answers with citations and can run Actions.
- **Search**: Quick search for documents. Onyx returns a ranked list of documents from your connected sources.

<Tip>
  Search mode appears only when your admin has connected at least one source and has not turned off the search UI.
</Tip>
